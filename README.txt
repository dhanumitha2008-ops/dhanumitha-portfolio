# Dhanumitha S — Personal Portfolio

## Preview on your laptop
1. Extract the ZIP file.
2. Open the `dhanumitha_personal_website` folder.
3. Double-click `index.html` to open it in a browser.
4. To edit it, open `index.html` in VS Code.

## Before publishing
- Replace `YOUR_EMAIL@example.com` with your preferred email address.
- Review all profile links and project descriptions.
- Add project GitHub links and screenshots if available.
- Confirm the CGPA and internship/certification details are current.

## Publish free
You can publish this static website using GitHub Pages:
1. Create a GitHub repository.
2. Upload `index.html`.
3. Open the repository Settings → Pages.
4. Select the main branch and root folder, then save.
